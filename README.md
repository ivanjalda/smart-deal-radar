# Smart Deal & Price Radar

Comparador de precios **reales** y ofertas verificadas: Moda, Tecnología, Supermercado, Belleza y Viajes.

- El ahorro se mide contra la **media real de los últimos 90 días**, nunca contra el precio tachado.
- Solo se muestran **tiendas verificadas** (5 criterios, cada uno con su prueba).
- Solo precios actualizados en las **últimas 48 horas**.
